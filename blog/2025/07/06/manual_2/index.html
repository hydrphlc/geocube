No Prism Configuration Manual

notes
By David G • Published on 07/06/2025 • Last update on 07/06/2025

Info¶

This section is an overview on using the tool without a prism. The tool can be utilized in a varity of ways with no prism.


First find the length of the overall rod configuration from rod tip to the desired mark on plumbing rod. To find this lay the configuration on the ground and place a bar level at the desired mark, perpendicular to the plumbing rod. Take a tape measure and measure from rod tip to the bar level.



With this rod height and with the help of a tape measure you can begin inverting. Add and subtract relative to the desired mark on the plumbing rod.

Add for Depth¶

If desired mark falls below the rim, then add (example: add 1.4ft to a 7ft configuration = 8.4ft depth)




Subtract for Depth¶

If desired mark falls above the rim, then subtract (example: subtract 1.2ft from a 7ft configuration = 5.8ft depth).


To get a pipe measure, first get the pipe invert measure, then push the rod tip upward towards the inside upper lip and measure. ( "pipe invert depth" - "upper pipe lip depth" = "pipe size" )

Here is an animation of the no prism process. In the scene, the green represents the desired rod marking.



Additionally, rods can be set to face upwards as seen in the photo.



With this configuration irregularly lipped pipes can be probed and measured.





Note: A bottom cap or bolt with washer is recommended for deep inverting.
